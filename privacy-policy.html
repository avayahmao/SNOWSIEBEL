Privacy Policy for SNOW Ticket Manager

Last updated: May 22, 2026

Overview

SNOW Ticket Manager is a Chrome browser extension that provides a sidebar interface for managing ServiceNow tickets. This privacy policy describes how the extension handles data.

Data Collection

This extension does not collect, store, or transmit any personal data to external servers.

Data Usage

The extension communicates exclusively with the user's own ServiceNow instance (avaya.service-now.com) to perform the following actions:

  • Read ticket lists and ticket details
  • Add work notes and update ticket status
  • Query tickets by number

All communication uses the user's existing browser SSO session. No separate credentials, API tokens, or login information is collected.

Data Storage

The extension does not store any user data outside the browser. No data is written to external databases, analytics services, or third-party servers.

Third-Party Services

This extension does not integrate with, send data to, or use any third-party services, analytics, or tracking tools.

Permissions

  • cookies — Used to read authentication cookies from the ServiceNow instance for API authentication via the existing browser session.
  • activeTab — Used to detect when the user is on a ServiceNow page and read the tab URL to identify ticket context.
  • scripting — Used to inject a content script into ServiceNow pages to access the page's CSRF token (g_ck) for authenticated API calls.
  • sidePanel — Used to display the extension's user interface as a browser sidebar panel.
  • host_permissions (avaya.service-now.com) — Required to make REST API calls to the ServiceNow instance.

Remote Code

This extension does not load or execute any remotely hosted code. All code is bundled within the extension package.

Changes to This Policy

This privacy policy may be updated if the extension's functionality changes. Any updates will be reflected on this page with a revised "Last updated" date.

Contact

For questions about this privacy policy, please contact the extension developer through the Chrome Web Store listing.
