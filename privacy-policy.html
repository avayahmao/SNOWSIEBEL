Privacy Policy for SNOW + Siebel Ticket Manager

Last updated: May 28, 2026

Overview

SNOW + Siebel Ticket Manager is a Chrome browser extension that provides a sidebar interface for managing ServiceNow tickets and Siebel CRM activities. This privacy policy describes how the extension handles data.

Data Collection

This extension does not collect, store, or transmit any personal data to external servers.

Data Usage

The extension communicates with the user's own organization servers to perform the following actions:

  • ServiceNow (avaya.service-now.com) — Read ticket lists and details, add work notes, update ticket status, query tickets by number
  • Siebel CRM (gct.avaya.com) — Create activity records on Service Requests using the Siebel JavaScript API
  • OCD API (ocd.avaya.com) — Fetch the user's Siebel backlog (open SRs and SRAs) for display in the sidebar

All communication uses the user's existing browser SSO sessions. No separate credentials, API tokens, or login information is collected from the user.

Data Storage

The extension does not store any user data outside the browser. No data is written to external databases, analytics services, or third-party servers.

Third-Party Services

This extension does not communicate with any third-party services, analytics, or tracking tools. It communicates only with the organization's own ServiceNow, Siebel CRM, and OCD servers as listed above.

Permissions

  • activeTab — Used to access the currently active ServiceNow or Siebel CRM tab when the user performs an action from the sidebar.
  • scripting — Used to inject content scripts into ServiceNow and Siebel CRM pages to access the page's CSRF token (g_ck) and Siebel JavaScript API for authenticated operations.
  • sidePanel — Used to display the extension's user interface as a browser sidebar panel.

Host Permissions

  • avaya.service-now.com — Required to inject scripts and make REST API calls to the ServiceNow instance.
  • gct.avaya.com — Required to inject scripts and automate Siebel CRM activity creation.
  • ocd.avaya.com — Required to fetch the user's Siebel backlog data from the OCD API.

Remote Code

This extension does not load or execute any remotely hosted code. All code is bundled within the extension package.

Changes to This Policy

This privacy policy may be updated if the extension's functionality changes. Any updates will be reflected on this page with a revised "Last updated" date.

Contact

For questions about this privacy policy, please contact the extension developer through the Chrome Web Store listing.
